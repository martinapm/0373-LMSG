## 🧩 Descripción del Repositorio

Este repositorio ha sido creado como parte del módulo **“0373. Lenguajes de Marcas y Sistemas de Gestión de Información”**, perteneciente al **Ciclo Formativo de Grado Superior en Desarrollo de Aplicaciones Web (DAW)** del **Instituto FOC**.

Aquí se recopilan los ejercicios y prácticas de las diferentes **unidades didácticas**, abarcando desde la estructuración de datos con **XML** hasta el diseño web con **HTML** y **CSS**, así como el uso de **XSL**, **XSLT** y **DTD**.

---

## 📚 Contenido del Repositorio

El repositorio incluye los materiales y ejercicios correspondientes a las siguientes unidades:

### 🧠 Unidad 01 – XML, XSL y DTD  
- Creación de documentos **XML** bien formados y válidos.  
- Validación de estructuras mediante **DTD**.  
- Transformaciones y presentaciones con **XSL** y **XSLT**.

### 🎨 Unidad 02 – HTML y CSS  
- Creación de páginas web con **HTML5**.  
- Diseño y personalización visual con **CSS3**.  
- Prácticas de maquetación y estilos adaptativos.

### 🧩 Unidad 03 – HTML, DTD y XML  
- Integración de **HTML** y **XML** en proyectos mixtos.  
- Validación estructural mediante **DTD**.  
- Ejercicios de manipulación de datos estructurados.

### ⚙️ Unidad 05 – HTML, XML, XSLT, CSS y XSL  
- Transformación avanzada de **XML** con **XSLT**.  
- Uso de **XSL** y **CSS** para la presentación de datos.  
- Desarrollo de páginas dinámicas y estructuradas.

### 💡 Unidad 06 – XML y HTML  
- Integración de **XML** en documentos **HTML**.  
- Ejercicios de vinculación y visualización de datos.  
- Consolidación de conocimientos sobre lenguajes de marcas.

---

## 🧰 Tecnologías y Herramientas Utilizadas

| Tecnología | Descripción |
|-------------|-------------|
| **HTML5** | Lenguaje de marcado para la estructura del contenido web. |
| **CSS3** | Lenguaje de estilos para el diseño visual de las páginas. |
| **XML** | Lenguaje de marcado extensible para estructurar y almacenar información. |
| **DTD** | Definición de tipo de documento para validar estructuras XML. |
| **XSL / XSLT** | Lenguajes para transformar y presentar datos XML. |

---

## 🧑‍💻 Objetivos de Aprendizaje

- Comprender la **importancia de los lenguajes de marcas** en el desarrollo y la gestión de la información.  
- Diseñar documentos **XML estructurados y validados** con DTD.  
- Aplicar **transformaciones XSLT** para generar distintas salidas de datos.  
- Desarrollar **interfaces web accesibles y profesionales** usando HTML y CSS.  
- Integrar diferentes lenguajes de marcas para **crear soluciones web completas**.
